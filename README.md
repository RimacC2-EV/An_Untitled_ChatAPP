这是 An_Untitled_ChatAPP！一款基于_____打造的快速、跨平台、简洁的聊天软件！让沟通变得更加简单！

* 它将会支持？

  * 手势快捷操作，一拉一滑间即可回复、多选消息，在 APP 内创建代办清单，甚至直接添加日程提醒！
  * 姿势感知反馈，使用手机内置加速度传感器和/或陀螺仪，感知您的姿势，自动在不同样式的界面间切换！针对不同场景提升便携度！

    * 当您将设备屏幕朝下平放时，它将通过压缩多余空间，提供更加适合手指轻轻滑动的操作逻辑！
