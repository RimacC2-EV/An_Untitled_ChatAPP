# 🌟 这是 An_Untitled_ChatAPP！

一款基于 开放通信协议 + 端侧AI能力 构想的跨平台聊天软件。<br>它不想做“另一个微信”或“另一个Telegram”，而是想尝试回答一个问题：

如果聊天软件不是为了“让你更快地回复”，而是为了“让你更自在地连接”，它会是什么样子？
<br>

它将会支持？
* 🖐️手势快捷操作

  * 一拉一滑间即可完成回复、多选消息，甚至在对话中直接创建待办清单或添加日程提醒。

  * 目标是让你的手指就是唯一的控制器！

* 🧘姿势感知反馈

  * 利用手机内置的加速度传感器和陀螺仪，感知你当下的使用姿态，自动切换界面布局：

    * 设备平放（如桌面会议）→ 自动切换为线性对话样式，方便斜眼扫读。

    * 屏幕朝下平放（防偷窥或短暂搁置）→ 界面压缩为半透明浮窗，只显示最新消息关键词。

    * 设备倾斜超过 15°（如躺在床上或行走中）→ 界面切换为扇形转轮布局，常用联系人沿拇指弧线排列，单手即可操作。

不需要任何设置菜单，拿起手机的那一刻，界面就是为你此刻的状态而生！
<br>

* 🫧 情绪可视化输入框（实验性）

  * 在这里，打字，不再只是冷冰冰的文本输入。

  * 在你输入时，输入框会基于本地（不上传到外部）进行语义分析，产生微妙的粒子动效。您稍后也可以考虑下载一款轻量的，仅为分析语义而生的 AI 模型来增强识别效果：

    *  输入“哈哈” → 泛起暖色跳跃的小光点。

    *  输入“唉……” → 背景浮现缓慢沉降的淡蓝色波纹。

这并非为了炫技，而是想让文字聊天重新拥有“语气”和“温度”。
<br>

* 🌌 异步“慢社交”模式

  * 如果你厌倦了“已读不回”的压力，可以开启此模式。

  * 发出的消息不会立刻送达，而是以 “信鸽飞行” 的可视化形式，在界面上缓慢飞行您设定的时长。

  * 对方收到时，会看到消息带着飞行的轨迹。
<br>

* 🤖 可选的本地AI助手（群组协作者）

  * 你可以选择将一个本地的 AI 助手“拉入”群聊（例如“旅行规划师”或“健康管家”），也可以使用您在第三方 AI 平台上的 API Keys 来接入其他模型！

  * 本地的 AI 助手不依赖云端，完全运行在你的设备上。它能听懂群友的讨论，并在需要时提供建议或总结。

  * 所有对话历史仅存于你的设备，AI 不会向任何服务器汇报。

  * 如果你不信任 AI，也可以完全不启用它。这是你的选择！
<br>

* 🔒 无手机号/邮箱注册

  * 参考一些前沿协议的设计，你的身份不依赖于手机号或邮箱。

  * 通过一次性二维码或链接建立连接，服务器不记录你的社交关系图。

  * 你的好友列表，只属于你，和你的设备。
